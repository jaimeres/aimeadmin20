# Enlaces verificables

Antes de enviar una respuesta que contenga referencias:

1. Localizar cada ubicación real antes de mencionarla.
2. Convertir cada referencia concreta en un enlace Markdown clicable a la ruta
   absoluta y línea exacta. Aplica también en tablas, listas, paréntesis y texto
   en línea.
3. No dejar el mismo identificador, ruta o elemento de código como texto suelto;
   que otra referencia cercana tenga enlace no lo sustituye.
4. Cuando una afirmación depende de más de una ubicación o proyecto, enlazar cada
   ubicación necesaria por separado.
5. Si no se verificó la ubicación, no afirmar el detalle como hecho; indicarlo
   como pendiente de verificación.

Auditoría final obligatoria: recorrer la respuesta completa antes de enviarla y
corregir cada referencia concreta que no sea un enlace real, existente y absoluto.
